## ✨ 🏛️ Prime Vision & Scope

NouGenScript serves as the foundational, mathematically rigorous engine for the entire NouGen ecosystem, encompassing diverse creative outputs under a single Abstract Syntax Tree (AST). This unified architecture ensures absolute consistency across all media types, from feature film screenplays and episodic television structures to detailed comic book panel breakdowns and precise marketing outreach sequences. By managing all paradigms—including code scripts (TypeScript, Python, Bash)—we provide a singular, deterministic pipeline for creative and technical workflows.

## 🧠 ⚙️ Core Architectural Invariants

The system is built upon a Dual-Plane Script Architecture, strictly separating the visual/talent-facing elements (DISPLAY PLANE) from the spoken/audio streams (SPEECH PLANE). This separation is critical for maintaining photorealistic identity consistency and precise timing. Furthermore, the SPITE Psychological Depth Engine tracks character shadow-self volatility and subtext leakage, allowing for nuanced, emotionally resonant delivery cues. Deterministic Persona & Behavioral Masks ensure that director and actor prompts are resolved via SHA-256 fingerprinting, guaranteeing predictable and high-fidelity character performance across every frame.

## 🐍 🛠️ Technical Stack & Dependencies

The engine leverages a robust, modern Python environment, ensuring rapid development cycles and high performance. Key dependencies include `pyyaml` for structured serialization and `pydantic` for strict data validation, which enforces the structural integrity required for high-resolution render manifests. Optional development dependencies include `pytest` and `ruff` for rigorous testing and code quality assurance, supporting rapid campaign turnarounds with confidence.

## ⚡ 🚀 Quick Start & Engine Usage

Initiate the engine via the unified command-line interface, `nougenscript`. The core workflow involves parsing source material (Fountain/Markdown/YAML), running subtext analysis against defined SPITE profiles, and composing behavioral masks and emotional spectrum cues. This rapid iteration capability allows talent and production teams to move from concept to structured script evaluation with minimal latency, directly supporting agile campaign deployment.
